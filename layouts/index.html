关于本站

📖 怎么阅读 本站是 GitHub 仓库 的在线阅读版。 每页内置文章开头，全文在打开时从 GitHub 直链加载（jsDelivr 备用线路）， 支持〈标题 + 正文开头 1500 字〉全文搜索与夜间模式。
🔄 同步机制 GitHub Actions 手动触发增量抓取（Actions → 同步源站 → Run workflow）， 新文章抓取后自动构建上线；每月 1 号发布全量 ZIP 快照到 Releases。
🧱 数据结构 Pages 只存放轻量索引页与搜索索引，正文按需拉取——站点体积不随文章数线性膨胀。 也可在仓库内按拼音首字母浏览 目录-*.md。
